기간
2026.08 – 현재
분야
웹 · 앱 프로토타입
역할
기획 · 구현 · 배포 1인 (강동 5기 풀스택 프로덕트 빌더 클로드코드 부트캠프)
핵심 결과
앱 · 웹 3종 직접 구현 (안드로이드 배포 1건 포함)

참여 범위

  • 교육 과정 프로젝트 — 기획 · 구현 · 배포 본인 단독
  • 도구: HTML/CSS/JS, React, Next.js, Expo, Claude Code

배경과 문제

개발자가 되려는 것이 아닙니다. 마케팅에서 실험용 랜딩페이지 · 이벤트 페이지를 만들 때마다 개발 일정을 기다려야 했고, 그 시간을 없애기 위해 배웠습니다.

목표

  • 랜딩페이지 · 이벤트 페이지 · 간단한 앱을 외주 없이 직접 만들고 고칠 수 있는 수준

전략

  • 마케터의 관점을 유지: "공유하고 싶은 결과 화면"을 먼저 설계하고 기능을 거기에 맞추기
  • AI 코딩 도구(Claude Code)로 실험용 페이지를 당일에 만들고 반응을 보고 고치는 속도 확보

실행

  • 오행야시(五行夜市) — 사주 · MBTI 소셜 게임 앱: 바이럴 소재로 기획, 프로토타입부터 Expo 안드로이드 앱 배포까지
  • otter-mind-money — 가계부 앱: 충동구매를 막는 "쿨다운 위시리스트"(담아두고 며칠 뒤 다시 묻는 구조)를 직접 설계 · 구현, 카메라 · Capacitor 네이티브 셸 포함
  • TripTalk — 숙박권 커뮤니티 · 커머스: 헤더 · 게시판 · 숙박권 구매 화면 구현 (Next.js)

성과

  • 앱 · 웹 3종 구현, 안드로이드 배포 1건부트캠프 과제 · 개인 프로젝트 기준 · 배포 링크 [입력 필요: 스토어/데모 링크]
  • 개발팀과의 대화 속도페이지 하나에 필요한 일의 양을 알게 되어 "가능한 것 / 비싼 것"을 구분해 요청할 수 있게 됨 (정성적 결과)
