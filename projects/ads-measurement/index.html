실무 프로젝트퍼포먼스 · 광고 운영·2024 – 2026.02

메타 · 네이버 광고 운영 및 측정 체계 설계

기간
2024 – 2026.02
분야
퍼포먼스 · 광고 운영
역할
소재 기획 · 집행 · 성과 분석 · 예산 배분 직접 담당
핵심 결과
소재 6종 비교 운영 → 예산 재배분 · 다음 캠페인 측정 기준(픽셀 · UTM) 마련

참여 범위

  • 채널: 메타(인스타그램 · 페이스북), 네이버 검색광고, 네이버 쇼핑 노출 최적화
  • 본인 역할: 소재 기획 · 집행 · 성과 분석 · 예산 배분 직접 담당 (1인)

배경과 문제

광고를 집행하고는 있었지만 어떤 소재가 왜 잘 되는지, 클릭한 사람이 실제로 구매했는지를 설명할 수 없었습니다.

스마트스토어 연동 구조상 클릭 이후 전환 데이터가 끊겨, 광고 성과를 CPC · 도달 수준에서만 판단하고 있었습니다.

목표

  • 같은 상품으로 소재를 비교해 효율 높은 소재에 예산을 모으기 — 지표: CPC, 도달, 빈도
  • 전환까지 측정되는 구조를 다음 캠페인 전에 마련하기

타깃과 인사이트

광고는 "돌리는 것"보다 "어디까지 측정되는지"를 먼저 확인해야 한다는 것을 배웠습니다.

전략

  • 소재 6종을 동시에 집행해 조건을 같게 두고 비교 → 저효율 소재 예산을 고효율 소재로 이동
  • 측정이 끊기는 지점을 찾아 픽셀 · UTM 도입안을 정리, 다음 캠페인의 측정 기준으로 삼기
  • 네이버 쇼핑 노출 로직에 맞춰 상품명 재구성 · 상세페이지 구성 기획으로 유료 광고 의존도 줄이기

실행

  • 메타 광고 소재 6종 동시 집행, CPC · 도달 · 빈도 비교 후 예산 재배분
  • 스마트스토어 연동 구조 분석 → 전환 데이터 단절 지점 확인 → 픽셀 · UTM 도입안 문서화
  • 네이버 쇼핑 노출 로직 기반 상품명 최적화, 상세페이지 구성 기획

성과

  • 저효율 소재 예산 → 고효율 소재로 재배분메타 광고 관리자의 CPC · 도달 · 빈도 비교 기준 · 소재별 세부 수치는 사내 자료로 비공개
  • 픽셀 · UTM 도입안 정리다음 캠페인의 전환 측정 기준 마련 · 도입 후 전환 수치는 재직 중 측정되지 않음
